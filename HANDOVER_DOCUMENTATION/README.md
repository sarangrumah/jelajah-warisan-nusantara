## 🏗️ SYSTEM ARCHITECTURE

### Technology Stack
- **Frontend:** React 18 + TypeScript + Vite + Shadcn UI
- **Backend:** Express.js + TypeScript + PostgreSQL
- **Authentication:** JWT with session management
- **Translation:** Hybrid system (Google Cloud + LibreTranslate)
- **File Storage:** Local uploads with cloud integration capability
- **Testing:** Vitest + Testing Library + Playwright
- **Deployment:** Docker + Nginx + PM2

### Key Features
- **Multilingual Support:** Automatic content translation with manual override
- **Content Management:** Comprehensive museum, collection, and heritage site management
- **User Management:** Role-based access control with approval workflows
- **File Management:** Secure file upload and media asset management
- **API Integration:** RESTful APIs with comprehensive documentation
- **Performance Optimization:** Caching, lazy loading, and code splitting
